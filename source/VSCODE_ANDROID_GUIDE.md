# دليل تشغيل تطبيق Internet Manager على VS Code ومحاكي أندرويد

يوضح هذا المستند الخطوات التفصيلية لإعداد بيئة التطوير، فتح المشروع باستخدام محرر Visual Studio Code، تشغيل محاكي الأندرويد، وبناء وتشغيل التطبيق حتى ظهور الواجهة بنجاح.

---

## أولاً: متطلبات النظام الأساسية
قبل البدء، تأكد من تثبيت الأدوات التالية على جهازك:
1. **حزمة تطوير Flutter SDK** (الإصدار 3.0 أو أحدث).
2. **بيئة Android Studio** مع أدوات Android SDK و Build-Tools.
3. **محرر Visual Studio Code** مع إضافات Flutter و Dart المثبتة.

---

## ثانياً: تجهيز المشروع في VS Code
1. قم بفك ضغط ملف المشروع `internet_manager_flutter_project.zip` في مجلد على جهازك.
2. افتح برنامج **Visual Studio Code**.
3. من القائمة العلوية، اختر **File > Open Folder** وحدد مجلد المشروع المستخرج (`internet_manager_app`).
4. افتح الطرفية داخل VS Code (الضغط على `` Ctrl + ` `` أو من القائمة **Terminal > New Terminal**).
5. قم بتحميل وحل تبعيات المشروع عبر تنفيذ الأمر التالي:
   ```bash
   flutter pub get
   ```

---

## ثالثاً: إعداد وتنشيط محاكي الأندرويد (Android Emulator)
1. افتح **Android Studio** ثم انتقل إلى **Device Manager** (أو افتح Device Manager مباشرة من شاشة ترحيب Android Studio).
2. انقر على **Create Device**.
3. اختر جهاز هاتف مناسب (مثل **Pixel 7** أو **Pixel 6**)، ثم انقر **Next**.
4. حدد صورة نظام حديثة (مثل **API 34** أو **API 33**)، قم بتحميلها إن لم تكن متوفرة، ثم انقر **Next** ثم **Finish**.
5. انقر على زر التشغيل (الأيقونة المثلثة **Play**) بجانب المحاكي الذي أنشأته لفتح شاشة الهاتف الافتراضية.

---

## رابعاً: تشغيل التطبيق على المحاكي عبر VS Code
1. تأكد من أن محاكي الأندرويد يعمل وتظهر شاشة نظامه الرئيسية.
2. في أسفل اليمين أو اليسار من شريط حالة **VS Code**، تأكد من ظهور اسم المحاكي النشط كجهاز هدف (Device Target).
3. اضغط على مفتاح **F5** من لوحة المفاتيح، أو انتقل إلى قائمة **Run and Debug** ثم انقر على **Start Debugging**.
4. سيقوم محرك Flutter بترجمة الكود، بناء حزمة التطبيق وتثبيتها تلقائياً على المحاكي.
5. خلال بضع ثوانٍ، ستظهر شاشة التطبيق الرئيسية (Dashboard) بجميع ميزاتها، عداد السرعة الحي، وشاشات إدارة التطبيقات والإحصائيات المطابقة للمواصفات.
